# 3.0.0 — Refonte de carrière

Remplace les plafonds individuels et les points universels par six domaines d’XP. Supprime les commandes de possession, réunit les présentations de match, rend la chronologie quotidienne indépendante de la granularité d’avance.

Ajoute les identités NBA 2025–2026 aux nouvelles parties, le renouvellement du monde, les marchés IA, la vie personnelle, des décisions d’intersaison, le journal persistant, les archives séparées et la migration des sauvegardes.

L’interface devient Aujourd’hui / Joueur / Carrière / Vie / Monde ; le menu ☰ contient réglages et sauvegardes. Les ressources versionnées permettent la transition depuis le cache V2.
